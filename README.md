# CBSE Pro Class 10 — Competency PDF Edition

The Question Bank page now focuses on **official CBSE Class 10 competency-based PDF resources** rather than an MCQ-only interface.

## Official resources included

### Mathematics
1. Curriculum Aligned Competency Based Test Items — Class 10
   https://cbseacademic.nic.in/cbe/documents/SAS_Maths-Class-10.pdf
2. CBSE Item Bank — Maths Class 10
   https://cbseacademic.nic.in/cbe/documents/Item-Bank--Maths---Class-10.pdf

### Science
1. Curriculum Aligned Competency Based Test Items — Class 10
   https://cbseacademic.nic.in/cbe/documents/SAS_Science-Class-10.pdf
2. CBSE Item Bank — Science Class 10
   https://cbseacademic.nic.in/cbe/documents/Item-Bank---Science-Class-10.pdf

### Complete CBSE hub
https://cbseacademic.nic.in/cbe/assessment.html

These resources are listed by CBSE under its Class X competency-based assessment resources. The page also contains other assessment collections.

## Run
Open `index.html` in a browser.

## GitHub Pages
Upload all files to a GitHub repository and enable **Settings → Pages → Deploy from branch**. Open the generated Pages URL.

## GitHub JSON sync
The optional GitHub sync remains available for your own custom question bank. Paste the Raw GitHub URL of `question-bank.json`.
